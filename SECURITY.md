# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | ✅ |
| < 0.3   | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub Issue for security vulnerabilities.

Report via GitHub's private [Security Advisories](https://github.com/elchika-inc/ts-review-graph/security/advisories/new) feature.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 7 days.
